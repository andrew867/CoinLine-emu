# Documentary emulator screenshots

These images show actual emulated terminal behavior, not mockups or generated artwork.

- `graphical-terminal.png`: the installed graphical terminal on-hook, with an active bitmap advertisement and the physical control panel. The native screenshot was scaled for the project README.
- `adsi-welcome.png` and `adsi-news.png`: two native VFD captures from the same qualified live ADSI session, before and after selecting News with the keypad. See [connected DTMF and ADSI navigation](../status/connected-dtmf-adsi-welcome-2026-11-25.md) for the corresponding firmware and on-wire evidence.
- `card-wallet.png`: cropped native panel captures of an active magnetic swipe and an inserted generic contact card during the isolated reader test. The graphic states follow the same reader events exposed to the terminal.
