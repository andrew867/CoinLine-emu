# Hardware validation status

The OEM and demo firmware completed INSTALL with erased serial EEPROM and blank SRAM. Both passed line and answer supervision, downloaded ten NCC records, and passed the keypad, card and coin checks. The terminal returned to service after a restart using firmware-written battery storage.

The Windows build presents the terminal panel with handset, housing, lock and vault controls. MAME plays the Voiceware and alerter paths. A carrier call verified handset capture, transmit audio and far-end disconnect.

See [firmware and NCC verification](ncc-install-firmware-stx-handoff-2026-11-23.md), [calling validation](line-jack-calling-2026-11-23.md), and the [device test guide](../../TESTING.md).
