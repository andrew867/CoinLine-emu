# Voiceware playback timing

The bank latch selects the Voiceware ROM window. The uPD7759 plays the selected sample and generates the completion edge observed by the terminal. See [Voiceware emulation](../voiceware-emulation.md) for playback and [firmware verification](ncc-install-firmware-stx-handoff-2026-11-23.md) for the recorded device behavior.
