CoinLine Terminal Emulator
=========================

Extract the archive to a writable folder. Install Python 3.11 or newer and the
runtime libraries for your platform.

  Ubuntu 24.04 x64:
    sudo apt install python3 python3-venv libsdl2-2.0-0 libsdl2-ttf-2.0-0 libfontconfig1 libxi6 libxinerama1 libportaudio2
  macOS 15 or later, Apple Silicon: brew install python sdl3 portaudio

Supply your authorized ROM images at these paths in the extracted folder.

  firmware/oem/flash.bin (256 KiB)
  firmware/graphical/flash.bin (1 MiB, optional graphical profile)
  roms/cl_millennium/voice_u16.bin and voice_u26.bin (1 MiB each)

From the extracted folder, run ./start-oem.sh --check and then ./start-oem.sh.
Run ./start-graphical.sh for the graphical profile, if its ROM is supplied.
Its separate configuration is coinline-graphical.ini and its state is under
data/graphical. Both profiles can use the local CO concurrently.
The terminal starts on-hook. Press H or click the handset photo or its button
to lift or replace the receiver.
The emulator includes a simulated central office and supports SIP calling.
To enable SIP or the dedicated ADSI routes, run ./setup-sip.sh once from the
extracted package. It installs pinned dependencies into .venv, not the system
Python. Both launchers automatically use this environment when present.
Copy the appropriate .example.ini to coinline.ini or coinline-graphical.ini,
fill in the [sip] settings, and run ./start-oem.sh --sip or
./start-graphical.sh --sip. Use --local for the simulated central office.
Without SIP or enabled ADSI routes, the local CO works without the .venv.

PortAudio captures audio from the default host microphone. To select an input,
set input_device under [audio] to a unique prefix of a PortAudio device name.
The emulator log reports the capture rate/channel count or why capture failed.
If no usable microphone is available, the handset transmit input is silent.
Set capture_enabled = false under [audio] to avoid opening a recording device.
On macOS, allow microphone access for the launching terminal or application;
on Linux, ensure the desktop audio session can access the recording device.
Terminal-generated audio continues through MAME's native speaker backend.

The direct ADSI service can use the shared adsi-routes.ini file
without changing either terminal's carrier account. See the example and
docs/Running.md for exact aliases, private service host and route validation.

Run CoinLine Server separately for OEM INSTALL and downloads. The default
NCC address is 127.0.0.1 and TCP port 4000. Copy coinline.example.ini to
coinline.ini to configure a different NCC port. For operator instructions and
front-panel controls, see docs/Running.md.

The full graphical images (SHA-256 prefixes 996a8ac5e81d, cb6be6c988bf and 33eaa2644e20)
use the generic asynchronous contact fixture for contact diagnostics; other
images retain their synchronous default. You can override smart_fixture
in the appropriate INI. The card wallet cycles magnetic and contact test
fixtures by clicking their names or pressing F and D. P swipes; [ inserts
the contact card and ] removes it. See docs/Running.md for additional fixture
slots and the default negative magnetic test card. Later-board profiles accept optional read-only internal contact fixtures
under [cards], using sam_slot0, sam_slot1 and sam_slot2. The included generic
module fixture does not provide payment authorization. The independent local
LAB ledger utility is app/lab_purse.py; run python3 app/lab_purse.py --help.

Copy data/oem/nvram between packages to carry forward an installed terminal.
For the graphical transition from cb6be6c988bf to 33eaa2644e20, copy only
battery, nvram and coin from the old digest's 11line/nvram/cl_millennium
directory to the new empty digest directory. Do not copy program_flash.
Retained-state startup and advertising resume passed; a fresh INSTALL on
the corrected image is a separate qualification gate.
Each run saves a display snapshot and logs under data/oem/logs. Use --headless
--seconds 18 for a bounded boot check and --record for a local handset recording.

The launcher allows automatic artwork frame skipping up to 10; use
--max-frameskip 4 if you prefer more redraws. --audio-buffer-ms sets the
host speaker buffer target where supported by the operating system's MAME
audio backend. The Windows scheduling preference does not apply on POSIX.
Zero selects MAME's default automatic frame skip limit (10); legacy values
of 11 are treated as 10 without rewriting existing configuration files.

Repository releases provide a matching source archive for this package.
License notices are in licenses/. SHA256SUMS.txt lists the packaged file hashes.
